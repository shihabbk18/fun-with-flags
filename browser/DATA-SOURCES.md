# Data sources

Country data: [mledoze/countries](https://github.com/mledoze/countries), ODbL 1.0. Snapshot downloaded 12 October 2026. [Full source and transformation notes](https://github.com/shihabbk18/fun-with-flags/blob/main/DATA-SOURCES.md) · [License](./ODbL-1.0.txt) · [Derived data](./countries.json)

Flags: [Flagpedia](https://flagpedia.net) / [Flagcdn](https://flagcdn.com), based on Wikimedia Commons vector files.

250 entries include all 195 UN member/observer countries, plus territories and other listed places. Capitals and regional groupings follow the bundled dataset; some countries have multiple capitals or disputed status.
